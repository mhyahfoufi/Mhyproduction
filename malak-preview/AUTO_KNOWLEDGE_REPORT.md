# تحديث معرفة ملك التلقائي

الفرع: mhy-ai-malak-preview

## التنفيذ
- مصدر الأعمال الوحيد هو assets/content-data.js الموجود في نفس نسخة الموقع التي تستضيف المعاينة؛ لا يتم قراءة main أو تعديله.
- تحميل المصدر عند فتح الصفحة وقبل كل إجابة، بعنوان متغير لتجاوز التخزين المؤقت. تُصفّر المعرفة قبل التحميل، ولا تُستخدم نسخة قديمة إذا فشل التحميل.
- استخراج العناوين العربية والإنجليزية، الأوصاف، الصور والأغلفة، روابط المشاهدة، التصنيف وحالة النشر. لا تظهر إلا حالة published، مع استبعاد visibility: private.
- knowledge.public.json أصبح ملف هوية وشخصية وترحيب فقط. أزيل منه الكتالوج المكرر والمعلومات الثابتة عن الشخصيات والإنتاج. لا تُستنتج سيرة شخصية من عنوان مقطع.
- وصف الاستوديو وروابط التواصل تُقرأ من الصفحة الرئيسية الحالية دون نسخ يدوي.
- تصميم CSS والصورة وأكواد اختيار الصوت والاستماع والإيقاف محفوظة. الروابط تقبل HTTP/HTTPS والبريد والهاتف فقط.
- الإضافة والتعديل والحذف تنعكس في الإجابة التالية أو عند إعادة فتح الصفحة؛ لا يُعاد كتابة سجل الإجابات القديمة تلقائياً.

## التحقق
نجحت 29 عملية تحقق آلية عبر node malak-preview/knowledge.test.cjs:
الفهرس الحقيقي (فيلم واحد، 8 أغانٍ، 10 صور)، البحث بالعربية والإنجليزية، إضافة فيلم وأغنية وتعديل الاسم والوصف والرابط وحذف كل منهما، إخفاء المسودة والعنصر الخاص، مسارات الصور، منع الحرق، المعلومة المجهولة، عناوين تحميل مختلفة، وفشل التحميل دون استخدام بيانات سابقة.
التجارب في الذاكرة فقط؛ لم تُضف عناصر وهمية إلى الكتالوج الحقيقي.
نجح فحص صياغة JavaScript. تعذّر تشغيل اختبار المتصفح لأن Chromium غير مثبت وتعذّر تنزيل حزمة صالحة. لم يتم اختبار Chrome Android أو أصواته فعلياً.

## المعاينة وحدود التنفيذ
هذا فرع GitHub مستقل، وليس عنوان استضافة HTML. رابط المستودع يعرض الملفات ولا يشغّل ملك. لا يوجد رابط هاتف مستضاف تم التحقق منه في هذه المرحلة؛ إنشاء استضافة جديدة يتعارض مع منع النشر. يمكن تشغيل المعاينة عبر خادم محلي من جذر المستودع: python -m http.server 8000 ثم فتح /malak-preview/ من جهاز يستطيع الوصول إلى ذلك الخادم.
عند استضافة الفرع لاحقاً، ستقرأ ملك الكتالوج الخاص بتلك الاستضافة. التغييرات في فرع آخر لا تنتقل تلقائياً بين فروع GitHub.
لم يُعدّل main أو المساعد الأصلي أو الكتالوج المركزي، ولم يحدث دمج أو نشر أو استخدام خدمة مدفوعة.
